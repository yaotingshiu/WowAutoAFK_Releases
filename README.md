WowAutoAFK 是一款專為《魔獸世界》玩家設計的自動化輔助工具[cite: 17]。本程式旨在協助玩家處理自動登入、掛機防斷等基本功能，以及自動釣魚，使玩家遊戲中更輕鬆地處理事務[cite: 17]。

透過極簡的現代化介面與深淺色主題，WowAutoAFK 提供最直覺的操作體驗，讓您告別繁瑣的重複性動作！

---

## ✨ 核心特色 (Features)

*   🔐 **自動登入系統**：支援帳號密碼加密儲存，一鍵快速進入遊戲[cite: 17]。多帳號管理功能讓切換角色變得輕而易舉。
*   🛡️ **智能掛機防斷**：內建多種掛機頻率與模式（如原地跳躍、隨機動作），完全模擬真人按鍵操作[cite: 17]。
*   🐟 **視覺化自動釣魚**：利用精準的圖像識別技術自動偵測浮標咬餌，支援收竿連擊與防呆機制[cite: 17]。
*   ⌨️ **快捷鍵整合**：自定義掛機與釣魚快捷鍵，支援快速開關[cite: 17]。
*   👻 **無干擾背景執行**：掛機全程可在背景處理(不包含釣魚)，完全不影響您的其他電腦作業[cite: 17]。支援縮小至系統匣與懸浮迷你視窗功能。

## 📖 詳細使用教學 (Tutorial)

### 步驟一：初次環境設定
1. **指定遊戲路徑**：開啟程式後，請於主介面「主程式路徑」欄位，選擇您的 `WoW.exe` 執行檔路徑[cite: 17]。
2. **調整延遲參數**：在「登入動作延遲」區塊，請依據您的電腦載入速度調整延遲秒數[cite: 17]。
   > 💡 **提示**：建議設為 10-15 秒以上以確保載入穩定[cite: 17]，若電腦配備較慢請適度調高。

### 步驟二：如何使用「自動登入」
1. 前往「帳號登入」分頁，輸入您的遊戲帳號與密碼，點擊「儲存帳號」。
2. 從清單中將該帳號設為「預設」。
3. 確認遊戲尚未開啟，點擊「自動登入遊戲」按鈕，程式將為您自動啟動遊戲並完成密碼輸入。

### 步驟三：如何使用「自動掛機」
1. 前往「自動掛機」分頁，在右側的**遊戲視窗列表**中，勾選您想要掛機的遊戲視窗（支援多開同時掛機！）。
2. 在下方設定「動作模式」（如：深度潛水）與「動作頻率」（如：原地跳躍）。
3. 透過設定好的「掛機快捷鍵」（預設 `Ctrl + F2`）即可快速啟動或停止掛機[cite: 17]。

### 步驟四：如何使用「自動釣魚」 (需保持遊戲畫面可見)
1. 前往「自動釣魚」分頁，設定您遊戲內的拋竿快捷鍵[cite: 17]。
2. 點擊「截取浮標圖片」按鈕，此時畫面會進入截圖模式，請將滑鼠區域精準框選至您的「釣魚浮標」[cite: 17]。
   *(範例圖示如下)*<br>
   <img width="83" height="84" alt="2026-07-17_162752" src="https://github.com/user-attachments/assets/75c26d5c-5c10-4055-8f77-8ffda55d092b" />[cite: 17]
3. 調整釣魚時間（支援連續釣魚或定時釣魚）。
4. 使用「釣魚快捷鍵」（預設 `Ctrl + F8`）正式開啟釣魚功能[cite: 17]。
   
> ⚠️ **釣魚注意事項**：
> * 為確保執行順暢，釣魚期間請避免操作鍵盤與滑鼠，以免干擾程式判定[cite: 17]。
> * 請盡量避免使用浮動較大、容易變形的特色浮標，可能會導致功能誤判[cite: 17]。

## ⚙️ 快捷鍵自定義 (Hotkeys)

您可以透過設定分頁的下拉選單，自由更改掛機與釣魚的觸發快捷鍵[cite: 17]。
*   **支援範圍**：系統支援 `Ctrl + F1` 至 `Ctrl + F9`[cite: 17]。
*   **自動互斥機制**：系統已內建防衝突保護，掛機與釣魚功能將無法同時啟動[cite: 17]（若在掛機中按下釣魚快捷鍵，系統會自動中斷掛機並切換至釣魚）。
